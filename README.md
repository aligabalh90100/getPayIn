# GetPayIn

A React Native (Expo) application built with TypeScript and React Navigation.  



## Prerequisites
Before running the project, make sure you have the React Native / Expo development environment set up.  
Follow the official docs here:  
 [React Native environment setup](https://reactnative.dev/docs/environment-setup)  


---

## Getting Started

### 1. Clone the repository
```bash
git clone git@github.com:aligabalh90100/getPayIn.git
cd getPayIn

### 2. Install dependencies
```bash
yarn install

### 3. Run the app
```bash
yarn android
